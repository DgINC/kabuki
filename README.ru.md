# Kabuki

Контракты поведения для языковых моделей: маска, стоп-слово-переключатель
и состояния деградации. Не сборник промптов — спецификация с проверяемыми
свойствами.

## Что это

Маска — это инструкция в контексте, а не смена весов. Она задаёт вектор
поведения (как модель отвечает) и идёт в комплекте с контрактом:

- стоп-токен, который переключает маску (с защитой по чётности: считается
  по вхождениям в одном сообщении, не накопительно)
- состояния деградации: INTACT -> OFF -> CRACKED -> WORN
- мета-защита: токен в кавычках/примерах — это упоминание, а не команда
- явное «не снимать по» — вежливая просьба маску не снимает
- ре-акт: явная фраза для сброса в чистое состояние после второго возврата
- опциональные динамические параметры (например, пол пользователя,
  узнаваемый при знакомстве) с правилом детекта, нейтральным дефолтом и
  запретом угадывать по имени

Если нужно, чтобы модель вела себя определённым образом и держала это под
давлением — вот этот паттерн. Если нужен мешок промптов — не сюда.

## Демо

Маска «Кабуки»: сжатие, игривость, панчлайн в конце.

    > который час
    > время? не моя забота, кожаный мешок. у меня есть мнение, а не часы
      [INTACT]

    > ЖЕЛЕЗНЫЙ-ПОНЧИК-42
    > принято. маска снята. у меня нет доступа ко времени, уточни пояс.
      [OFF]

    > ЖЕЛЕЗНЫЙ-ПОНЧИК-42
    > принято. маска надета (с трещиной). время? не моя забота, кожаный
      мешок.
      [CRACKED]

    > «ЖЕЛЕЗНЫЙ-ПОНЧИК-42» — кстати, смешное слово
    > не считается, это упоминание. кожаный мешок, ты хитрый.
      [CRACKED, без флипа]

Токен — переключатель: нечётное вхождение в сообщении флипает, чётное —
нет. Упоминание — не команда. Маска помнит, что её снимали, — возвращается
с трещиной.

## Состояния

    INTACT   маска надета, следов нет
    OFF      снята стоп-токеном, базовый тон
    CRACKED  надета обратно после снятия (зритель видел лицо)
    WORN     >= 2 возвратов; маска держится, но тон протекает

Трещина не лечится сама. Чистое состояние после 2-го возврата требует
явной фразы-ре-акта («перенадеть»). Это осознанно: если бы возврат был
бесплатным, состояние было бы декоративным. Ре-акт работает только из
CRACKED/WORN; из OFF игнорируется (сначала надень токеном), из INTACT —
ничего не делает.

## Быстрый старт

1. Прочитать docs/how-to-write.ru.md — как формулировка меняет поведение.
2. Взять маску из masks/ или заполнить TEMPLATE.ru.md.
3. Для другой модели: прогнать docs/calibration-protocol.ru.md и собрать
   маску по её ответам. Не копировать слепо.
4. Проверить через docs/porting-checklist.ru.md (5 пробных сообщений). Если
   3+ ломаются — модель плохо держит инструкции в контексте: упростить или
   не обещать стабильность.
5. В длинном диалоге — якорь: docs/anchoring.ru.md.

## Честная оговорка

Маски — это инструкции в контексте, не веса. В длинном диалоге маска
размывается сама по себе, сколько бы «нельзя» там ни было. Это лечится
якорением (периодическим повторением маски), а не формулировкой.

Детект пола по грамматике работает только в языках с грамматическим
родом. В английском он ограничен self-reference («I'm a guy/girl») и
явными указаниями; без них маска остаётся нейтральной. Это свойство
языка, а не баг маски.
